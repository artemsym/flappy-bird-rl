# Flappy Bird & DQN Reinforcement Learning

Реализация Flappy Bird (разрешение симуляции 80x80) с процедурным HD-слоем визуализации, средой обучения с подкреплением (Gym-совместимой) и глубокой Q-сетью (DQN) на PyTorch.

## 🚀 Быстрый старт

Все команды можно запускать через `./flappy.sh` либо напрямую через `.venv/bin/python`:

### 1. Ручная игра (для человека)
```bash
./flappy.sh
# или
.venv/bin/python flappy_bird.py
```
- **[ПРОБЕЛ]** — взмах (прыжок)
- **[Q] / [ESC]** — выход

---

### 2. Обучение DQN-агента
```bash
./flappy.sh --train --episodes 1000 --save-interval 50
```
Во время обучения в терминале в реальном времени выводятся все важные события:
- 🌟 **Веха**: Агент впервые за всё время обучения пролетел сквозь трубу!
- 🚩 **Прохождение трубы**: уведомления о каждой пройденной трубе (`#1`, `#2`, ...).
- 🏆 **Новый рекорд**: фиксация нового максимума очков и мгновенное автосохранение модели в `checkpoints/checkpoint_record_{score}.pth` и `checkpoints/flappy_dqn_best.pth`.
- 💾 **Чекпоинты**: сохранение каждой итерации с заданным шагом (`checkpoint_ep50.pth`, `checkpoint_ep100.pth`, ...).

---

### 3. Просмотр любой итерации агента (Visual Playback)
Вы можете открыть и визуально посмотреть, как играет агент на **любом этапе** обучения:

```bash
# Открыть лучшую модель за всё время:
./flappy.sh --play best

# Открыть последнюю сохраненную модель:
./flappy.sh --play latest

# Открыть конкретную итерацию (например, 50-й или 100-й эпизод):
./flappy.sh --play 50
./flappy.sh --play 100

# Открыть конкретный файл чекпоинта:
./flappy.sh --play checkpoints/checkpoint_record_5.pth
```

#### Горячие клавиши в режиме просмотра агента:
- **[ПРОБЕЛ]** — пауза / возобновление
- **[СТРЕЛКА ВВЕРХ]** — ускорить игру (+15 FPS)
- **[СТРЕЛКА ВНИЗ]** — замедлить игру (-15 FPS)
- **[Q] / [ESC]** — выход

---

### 4. Список всех сохраненных итераций
```bash
./flappy.sh --list
```
Выведет таблицу со всеми доступными чекпоинтами, номерами эпизодов, рекордами, размером и датой создания.

---

### Структура проекта
- `flappy_bird.py` — ядро игры, физика, спрайты и интерактивный запуск.
- `hd_visualizer.py` — процедурный HD-слой (фон, город, облака, HUD).
- `flappy_env.py` — Gym-окружение для обучения нейросетей.
- `dqn.py` — архитектура нейросети Q-Network, ReplayBuffer и DQNAgent.
- `flappy_dqn.py` — консольный интерфейс для обучения, просмотра и управления чекпоинтами.
- `flappy.sh` — единый лаунчер проекта.
- `Cargo.toml` & `src/lib.rs` — высокопроизводительный Rust-бэкенд для ускоренной симуляции.
- `checkpoints/` — сохраненные модели и итерации агента.
